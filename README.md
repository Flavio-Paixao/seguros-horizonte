# Seguros Horizonte - AWS Infrastructure

Multi-account AWS infrastructure for Seguros Horizonte, a fictional insurance company.

## Project Overview

This repository contains infrastructure-as-code (IaC) using Terraform for deploying a production-grade AWS environment with:

- Multi-account architecture (dev, staging, prod)
- LGPD compliance (Brazilian data protection law)
- PCI-DSS compliance (payment card security)
- High availability and disaster recovery
- Comprehensive security and monitoring
